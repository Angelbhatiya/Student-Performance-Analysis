# Student-Performance-Analysis
A Python and pandas based project that analyzes students marks and calculates total, average marks, PASS/FAIL result and highest-performing student, lowest performing student.

# What problem did I solve?
I analyzed students' academic performance in an easy and organized way instead of checking each student's marks manually. The project helps calculate and understand students' overall performance.

# What data did I use?
I used a CSV file containing student marks. The data included:
* Roll Number
* Student Name
* Math
* Physics
* Chemistry
* English
* Computer

# What analysis did I perform?
I used Python and Pandas to:
-> Read the student data from the CSV file
-> Calculate total marks for each student
-> Calculate the average marks
-> Check whether students passed or failed based on their subject marks
-> Find the student with the highest and lowest total marks

# What did I learn/find?
I learned how to use Pandas, to read and analyze CSV data, create new columns, calculate averages and totals, and find useful information from a dataset. I also learned how small amounts of data can be analyzed systematically instead of doing calculations manually.
